## Версионирование данных (DVC)
Исходные файлы данных (`data/raw_dataset.csv`) не хранятся напрямую в репозитории Git, поскольку система Git оптимизирована для текстового исходного кода и при хранении больших табличных или бинарных файлов резко разрастается размер истории репозитория. Для отслеживания версий данных используется DVC: в Git фиксируется только компактный метафайл `raw_dataset.csv.dvc` с MD5-хешем и размером набора данных, а сами данные хранятся отдельно.
